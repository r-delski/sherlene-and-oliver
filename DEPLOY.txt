HOW THIS INVITATION IS PUT ONLINE (GITHUB PAGES)
================================================

All the site's files sit together in one folder, with no sub-folders:

  index.html   the page
  style.css    the design
  script.js    countdown, music, auto-scroll, RSVP settings
  song.mp3     the background song (optional)
  *.svg        sample pictures

RSVP replies go to a Google Form and are read in its Google Sheet.


UPLOADING OR UPDATING
---------------------
1. Open the repository on github.com.
2. Click "Add file" > "Upload files".
3. Drag in the files that changed (or all of them).
   A file with the same name replaces the old one.
4. Click "Commit changes". The site updates in a minute or two.

First time only: Settings > Pages > Branch "main", folder "/ (root)" > Save.
The address is then  https://YOUR-USERNAME.github.io/REPOSITORY-NAME/


YOUR OWN PHOTOS
---------------
Save them with exactly these names, in this same folder, and upload them:

  couple.jpg   main photo at the top (portrait, about 900 x 1200)
  story.jpg    photo beside "Our adventures" (portrait, about 1000 x 1250)
  photo1.jpg ... photo6.jpg   gallery photos (square works best)

Each .jpg automatically replaces the sample drawing with the same name.
Keep each photo under about 500 KB so the page opens quickly on phones.


THE SONG
--------
The site plays song.mp3 on a loop after the seal is tapped. Without that file
it plays a soft built-in melody. A public repository lets anyone download the
file, so use a song you are allowed to share.


THE RSVP FORM
-------------
The website form sends answers to the Google Form set in GOOGLE_FORM at the
top of script.js. If you rename a choice or add a question in Google Forms,
that block must be updated too, or replies will be rejected without warning.


BEFORE YOU SHARE THE LINK
-------------------------
- Replace the sample details in index.html: the story, the RSVP date,
  Rodel's number, the best man and the maid of honor.
- Send yourself one test RSVP and check that it shows up in the Google Form.
